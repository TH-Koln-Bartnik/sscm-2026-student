# Group project tools

| File | What it is |
|---|---|
| `project_check_cell_demo.ipynb` | The check cell (five tests T1–T5) demonstrated on the UrbanRide bike data. Copy its last cell into your notebook, unchanged. |
| `project_check_cell.py` | The same check cell as plain text. |
| `project_animation_demo.ipynb` | The animation template played on an example, plus the code that turns your `results.json` into `animation.html`. |
| `animation_template.html` | The template page; it reads its numbers from `results.json`. Restyle a copy if you like. |
| `example_results.json` | Illustrative results of the bike line in the format the template reads. |

The rules are on the project page of the online script.
