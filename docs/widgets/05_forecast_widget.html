Actuals and forecasts

New forecast = old forecast + α × (last actual − old forecast)

Twenty days of a noisy series; on day 11 the level jumps up and stays. Move α: near 0 the forecast is calm and slow to notice the jump, near 1 it is nervous and copies yesterday's noise. Start value = the first actual.

Tracking signal = RSFE ÷ MAD · RSFE = all errors so far added up (with signs) · MAD = all |errors| so far ÷ weeks so far

A fixed forecast of 100 a week against twelve weekly actuals that creep upward. Edit the actuals or the forecast. Inside ±4 the misses are noise; a point outside is a signal: the forecast is biased, re-set it.
